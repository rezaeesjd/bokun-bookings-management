# Version 1.2.7 — keep Analytics light (no isolated auto-dark)

The Analytics and Business Results views carried their own
`@media (prefers-color-scheme: dark)` palette. On a dark-mode browser that made
only those views flip to a dark background (dark KPI cards, near-white heading
text on the white page) while the rest of the light-only dashboard stayed
light — a jarring, broken-looking mismatch (not host-theme interference, as it
first appeared).

The dark `--an-*` palette is kept for a future, coordinated app-wide dark mode,
but it is now gated behind an explicit `.bokun-theme-dark` opt-in class instead
of auto-applying from the OS preference. With nothing setting that class,
Analytics stays light and consistent with every other surface. No data, chart
logic, categorical palette or behavior changed.
