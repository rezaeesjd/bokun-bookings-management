# Version 1.4.0 — 12-month Analytics window + filterable Business Results

## Longer history, default last 3 months

The Analytics source table now retains a rolling **12 months** of bookings
(was 3), and the dashboard **defaults to the last 3 months** — widen the date
range (new `3m` / `6m` / `All` presets) to see further back. Both windows are
filterable:

- `bokun_analytics_window_months` (default **12**) — how much is retained/available.
- `bokun_analytics_default_view_months` (default **3**) — the default view, capped at the window.

Older history fills in as imports re-fetch it, so the extra months build up
going forward. Reset returns to the 3-month default.

## Business Results is now a filterable metric

"Business Results" moves out of the separate toolbar toggle and into the
**metric segmented control** (Bookings · Participants · Revenue · Net revenue ·
**Business Results**). Selecting it shows a breakdown of **how net revenue is
calculated for the bookings currently filtered** — so the sidebar filters, date
range, search and chart drill-downs all change it, and you can see exactly which
bookings and numbers produce the margin:

- Tiles: Bookings, Catalog-matched, Catalog coverage %, Gross earned, Partner
  cost, Net margin, Avg net margin / booking.
- A margin waterfall: **Gross earned → − Partner cost → = Net margin** (scoped to
  the filtered set's main currency; money is never summed across currencies).
- A note for gross from bookings not in the partners catalog (no net price, so
  excluded from margin).
- The per-booking inputs are the **Records** table below (Gross, Net price, Net
  revenue columns), which reflect the same filters.

**Overhead stays business-wide.** Fixed monthly overhead doesn't shrink when you
filter to a subset, so it's shown as a fixed line (not filtered), with a **"View
full overhead P&L →"** button that opens the detailed, business-wide P&L
(overhead, operating profit, waterfall, monthly trend) — unchanged, just reached
from here instead of a separate toggle.

No data model or net-revenue formula changed; this surfaces the existing
per-booking margin computation in a filter-driven view. Tests: analytics
interaction suite extended to 18 checks (default-view window + Business Results
metric); full suite green.
