# Version 1.2.9 — friendlier view tabs (segmented control + top breathing room)

The Bookings / Analytics / Messages view tabs were correctly wine-colored but
sat flush against the top edge (hugging the WP admin bar) and read as three
loose, cramped buttons.

- The tabs are now a **contained segmented control**: a sunken, pill-shaped
  track holds the three tabs, so they read as one coherent switch instead of
  three detached buttons. Inactive segments are quiet (muted text, transparent),
  hover is soft wine, the active segment is solid wine with a subtle lift.
- Comfortable sizing: each segment is a 40px-min-height target with roomier
  horizontal padding.
- **Top breathing room**: the tab bar gets `padding-top` (not margin, to avoid
  margin-collapse through the Elementor/theme wrapper) so it no longer sticks to
  the admin bar.
- The theme-leak hardening from 1.2.8 is preserved (full button reset +
  `!important` on visual props), so host-theme button chrome still can't bleed in.

CSS-only; no data or behavior changed.
