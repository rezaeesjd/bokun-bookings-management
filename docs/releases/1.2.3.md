# Version 1.2.3 — centralized support and deployment

The administrator-reviewed Gmail Messages implementation is the single support
inbox. The separate IMAP/Anthropic prototype is superseded. Existing mailbox
connections, encrypted settings, conversation history and drafts stay in
WordPress; they are not stored in GitHub or overwritten by code deployment.

## Source and deployment

- `rezaeesjd/bokun-bookings-management` on `main` is the central deployment source.
- The consolidation preserves the prior upstream history. Its initial merge is
  `2382557ea475186327a1720de9229489d9b1d7c7`.
- GitHub auto-sync is enabled on the booking portal. A signed push hook triggers
  updates; administrative checks and the hourly cron provide fallback checks.
- Packages resolve to immutable commits. Failed or unconfirmed updates cannot
  become installed-commit receipts. Authorization headers are restricted to
  exact HTTPS GitHub hosts and the configured repository.
- Tests, CI definitions and agent instructions are excluded from deployment
  archives. Secrets, environment files and databases are never committed.
- Every pull request and every push to `main` runs regression checks. Because
  `main` is the production deployment branch, review changes before pushing;
  automatic deployment is not an additional human approval gate.

## Validation

348 automated checks cover dashboard authorization/privacy, message ingestion,
context isolation, immutable approvals, uncertain-send handling, acknowledgement
reviews, browser editing/navigation, booking import pagination/locking and
GitHub updater authentication/receipts. GitHub Actions runs PHP suites on 8.2
and 8.4 and the browser suite on Node.js 22. Real mailbox permissions, live
booking data and AI quality still require separate operational verification.

Gmail polling remains enabled. AI drafting remains requested-only, and customer
sending still requires the administrator's explicit approval of the saved
reply. The optional Bókun booking-event webhook is separate from GitHub
deployment and remains disabled until explicitly configured.
