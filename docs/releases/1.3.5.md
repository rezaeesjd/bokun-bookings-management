# Version 1.3.5 — deep-linkable dashboard tabs

The Bookings / Analytics / Messages view tabs are now reflected in the URL hash,
so each tab is its own address and a refresh reopens the tab you were on:

- `…/dashboard/#bookings`
- `…/dashboard/#analytics`
- `…/dashboard/#messages`

Clicking a tab updates the hash (via `history.replaceState`, so it does not add
browser-history clutter or jump-scroll). On load — and on back/forward or a
manual hash change — the tab named in the hash is restored, with Analytics
lazy-initializing as usual. An absent or unknown hash keeps the default Bookings
tab, and a hash for a tab the current role can't see is ignored. JS-only.
