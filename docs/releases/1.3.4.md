# Version 1.3.4 — reword the booking role label

The booking-manager role's descriptive label (shown on the Dashboard Access
admin screen) now reads **"Booking manager — All Booking data and actions"**
instead of "Booking manager — everything except Analytics" — stating what the
role can do rather than what it can't. No capability or behavior changed; the
account bar still shows the short label ("Booking manager").
