# Version 1.3.3 — account bar at the bottom, shorter role label

- The "Signed in as … · Sign out" account bar now sits at the **bottom** of the
  dashboard instead of the top.
- The account bar shows a **short role label** (Admin / Booking manager /
  Generic) without the descriptive "— everything except Analytics" suffix. The
  full descriptive labels are still used on the Dashboard Access admin screen.
