# Version 1.2.4 — Messages inbox sort control

The Messages inbox gains a **Sort** control in its toolbar, beside the Status
filter and Search. It changes only the order of the conversation list; it does
not send, draft, or alter any message.

## Sort options

- **Last message (newest)** — the default and preselected option. Preserves the
  historical order: the conversation with the most recent message first
  (`latest_at DESC`).
- **Last message (oldest)** — the longest-waiting conversation first, to help
  avoid leaving anyone unanswered.
- **Priority (needs reply first)** — orders by workflow state (needs reply, then
  needs review, then answered, then handled), with the most recent message first
  within each group.

The sort is chosen from a fixed server-side allowlist, so the `ORDER BY` clause
is always a trusted constant and never built from request input. The chosen sort
combines with the existing business, status and search filters and with
pagination. Requests that omit the parameter keep the previous default order, so
the change is backward compatible.

A future option to sort by **travel date** (soonest departure first) would need a
dedicated indexed column populated from the booking snapshot plus a one-time
backfill; it is intentionally not included here.
