# Version 1.2.6 — per-business color on booking cards

The 1.2.5 refresh unified the whole dashboard onto one wine palette, which made
the two operators look identical on their booking cards. This restores a clear
visual distinction so an admin can tell at a glance which business a booking
belongs to.

- Two per-business accent tokens in the design system: **Via Florence** (and any
  default vendor) keeps the wine brand; **Florence Adventures** gets a distinct
  teal.
- Each booking card carries a colored **left-edge stripe** in its business
  color, and the vendor label and Reserve link use the same color. The stripe is
  keyed off the vendor label already in the markup (`:has()`), so there is no
  markup change; cards without a vendor keep the neutral border.

CSS-only; no data, buttons or behavior changed.
