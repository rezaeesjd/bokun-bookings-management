# Version 1.3.1 — booking card footer always three stacked rows

The booking card footer (`.bokun-booking-dashboard__meta-line`) used
`flex-wrap: wrap` with `justify-content: space-between`, so the **Message
client** button, the status tags, and the Viator/Bokun link buttons wrapped
inconsistently — sometimes two groups shared a line, sometimes three.

The footer is now a vertical stack of exactly three rows, each on its own line:

1. **Message client** button
2. **Status tags** (they still scroll horizontally if a card has many)
3. **Link buttons** — Tag Editor / Viator link / Bokun link, grouped on one row
   (wrapping only if the card is too narrow)

Markup: the Tag Editor and Viator/Bokun links are wrapped in a single
`.bokun-booking-dashboard__link-row` so they share row 3. CSS-only layout change
otherwise; no data, buttons or behavior removed.
