# Version 1.2.5 — design system + Bookings dashboard refresh

A visual modernization (polished refresh — no layout or flow changes) that
introduces a shared design system and applies it to the public Bookings
dashboard. Light mode only for now.

## Design system

- New `assets/css/bokun-design-system.css` defines the plugin's design tokens as
  CSS custom properties on `:root`: one brand (wine/burgundy) scale, a single
  slate neutral ramp, semantic state colors, a spacing scale, radii, calm
  low-alpha shadows, a focus ring, and a real system font stack with a type
  scale. Base typography and an accessible `:focus-visible` ring are scoped to
  the plugin's own containers so the rest of the WordPress theme is untouched.
- It is registered first and set as a dependency of the dashboard stylesheet, so
  `bokun_front.css` consumes the `--bk-*` tokens.

## Bookings dashboard

- The dashboard chrome, which previously mixed a blue control theme with the
  wine brand accent, is unified onto the single brand + neutral token palette:
  container, toolbar, fetch link, controls panel, search field, status filter,
  status tabs, booking cards, titles, status badges and the dual-status section.
- Loud gradients and heavy drop shadows are replaced with calmer tokenized
  surfaces; spacing, radii and type now follow the scale.
- Behavior, markup structure and access rules are unchanged; this is a
  CSS-level refresh. The staff-only controls and the public/staff boundary from
  1.2.x are untouched.

Analytics and the Messages inbox will adopt the same tokens in follow-up
changes.
