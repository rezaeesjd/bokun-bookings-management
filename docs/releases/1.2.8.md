# Version 1.2.8 — fix dashboard view tabs + guard against theme button leaks

The three dashboard view tabs (Bookings / Analytics / Messages) still used the
old WP-admin blue for the active state, and because they are `<button>`s the
host theme / Elementor button chrome (its own background, border, box-shadow,
uppercasing) leaked into them — producing the inconsistent "wine pill + blue
underline" look.

- The view tabs are rewritten as wine pills (inactive = neutral outline, hover =
  soft wine, active = solid wine), using the design tokens. The styling is
  applied at raised specificity with `!important` on the visual properties and a
  full button reset (`appearance`, background, border, box-shadow, text-shadow,
  text-transform), so host-theme button styles can no longer bleed through.
- A general theme-leak guard normalizes `font-family`, `text-transform`,
  `letter-spacing` and `text-shadow` on buttons and form controls across all
  plugin surfaces — without touching each component's own background, color or
  border — so other body buttons stay consistent under aggressive themes too.

CSS-only; no data or behavior changed.
